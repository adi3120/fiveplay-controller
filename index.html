FivePlay Controller

Play fiveplay.lol with a game controller, in GTA V's original controller layout. It is a bookmark, so there is nothing to install. Use Google Chrome.

  1. Show the bookmarks bar (Cmd + Shift + B on a Mac, Ctrl + Shift + B on Windows and Linux), then drag this button onto it:
    FivePlay Controller
  2. Connect the controller (Bluetooth or USB). On a Logitech F310, set the switch on the back to D and keep the Mode light off.
  3. Open fiveplay.lol, click the FivePlay Controller bookmark, then press any button on the controller.
  4. Click inside the game once. Chrome only lets the controller look around, aim and shoot after a real click.

Press Back + A on the controller (or click the bookmark again) to see the button layout. Reloading the page turns the controller off, so click the bookmark again after each reload.

Prefer it to start by itself? With Tampermonkey or Violentmonkey installed, install the userscript instead.

If dragging does not work: right-click the green button, choose Copy Link Address, then add a bookmark in Chrome's bookmark manager and paste it as the URL. Source, full controls and help: https://github.com/adi3120/fiveplay-controller. Bookmark size: 31,861 characters.
